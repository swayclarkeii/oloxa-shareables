# Oloxa Shareables

Public, anyone-can-use files from Oloxa. Drop a file in here when you want to hand it
to a client or teammate without emailing an attachment.

Grab the raw link to any file by opening it on GitHub and clicking **Raw**, or point
someone at the file's normal page and they can read and copy it straight away.

Nothing sensitive goes in here: no keys, no client data, no internal notes. Public
means public.
